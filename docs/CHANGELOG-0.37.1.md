# Hearth Engine 0.37.1 · Убрана скрытая граница после расширения

«Расширить карту» меняет только рельеф. Убрана автоматическая невидимая стена, которая раньше вычислялась из размера карты даже при отсутствии заданных границ.

В стартовой «Долине тихого огня» ограничение движения выключено. Повторное расширение не создаёт и не перемещает стену. Ограничение включается и задаётся только в «Границы карты». «Поставить границу по краю рельефа» явно записывает текущие координаты; «Убрать ограничение» отключает стену после применения.

В верхней панели видно состояние «вкл/выкл». Когда граница отключена, голубого контура нет; серый квадрат на схеме показывает только размер рельефа. Стены объектов, деревья и другие обычные коллизии сохраняются.

Выход за размеры рельефа больше не мешает сохранять и загружать игрока, выброшенные предметы и побеждённых персонажей. Проверки корректности чисел и ссылок сохранены.

Регрессионный сценарий: стартовый пример, форма расширения 80 → 100 м, движение с 38 до 62 м в четырёх направлениях через старый и новый края, реальные коллизии сцены, игрок и NPC, повторное расширение, явное включение/снятие ограничения, сохранение за краем рельефа.

В Залтане прежний периметр 800 × 800 м сохранён как явно записанная настройка. Его можно изменить или убрать в «Границы карты». География и сюжет сохранены. Формат проекта 24, сохранения 8, contentVersion Залтана 4.

Для обновления сохраните текущий проект, откройте hearth-editor.html из нового архива и загрузите свой .hearth.json.
