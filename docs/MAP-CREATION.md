# Создание карты без границ

В верхней панели нажмите **＋ Создать карту**, укажите название и **размер стороны в метрах** (от 20 до 2000, допускаются дробные значения), затем нажмите **Создать карту**. Например, 800 создаёт карту 800 × 800 м.

Получится пустая ровная карта без объектов и квестов, со стартом игрока в центре. **Невидимых границ движения нет**: размер задаёт площадь редактируемого рельефа, а не стену для игрока. Весь участок уже выбран для лепки; можно сразу поднимать землю, рисовать покрытие и добавлять объекты. Явную границу при необходимости можно включить отдельно в **Границы карты**.

Форма не меняет текущий проект до нажатия **Создать карту**. Создание можно отменить через **↶** или **Ctrl/⌘+Z**, включая возврат объектов, рельефа и границ предыдущего проекта. **Скачать проект**, **Скачать редактор HTML** и **Скачать игру HTML** сохраняют новую карту с выбранным размером и выключенными ограничениями.

Формат проекта остаётся 24, формат сохранения — 8. Стартовый пример и существующие проекты не изменены.
