# Hearth 0.26.0 · Холмистые города

- Новый вид генерации: «Холмистые города · общий сюжет», CLI `--mode highlands`
  и API `generateAdventure({mode: 'highlands'})`.
- Три застроенных города на нижних плато скрыты друг от друга за грядами;
  четвёртый город расположен на вершине высотой 26 / 30 / 34 м.
- Кольцевая дорога огибает холмы, отдельный подъём соединяет нижний город
  с крепостью. Навигация использует дорожный граф и повороты.
- Общее расследование: пропавший караван → поддельная печать → карта русел →
  приказ горного совета. В финале можно выбрать совместное управление
  водохранилищем или открытие старых русел с другой ценой и последствиями.
- Три необязательные истории помогают жителям разных городов и дополняют
  эпилог; старосты реагируют на решение, вода возвращается на площади.
- Для больших миров дальность камеры, тумана и обзор редактора масштабируются
  с картой. Старые режимы генерации, форматы проекта v17 и сейва v6 сохранены.
- Готовый пример: examples/generated-highlands.hearth.json. Он встроен в
  hearth-editor.html и dist-game/game.html.

Проверки: 171 тест прошёл. Новые проверки охватывают 45 seed, обе развязки,
побочные эпилоги, сохранения, обзор между городами с приподнятых точек на
окраинах, связность дорог и движение по сюжетному маршруту во всех размерах
с настоящими коллизиями зданий и moveCharacter, без прыжков. Интеграционный
тест проверяет создание карты, экспорт, дальность камеры/тумана и отмену.
Собраны редактор, автономный редактор HTML и автономная игра.

Полноценная визуальная проверка WebGL в браузере в этой среде не выполнена.
Дома декоративные, без интерьеров. Подробности: [HIGHLANDS.md](HIGHLANDS.md).
