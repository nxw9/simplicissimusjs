# Архитектура 0.26

Проект v17 — строгий JSON (Zod), игровые сохранения — v6. Миграции открывают
старые форматы без изменения исходного файла; неизвестные будущие версии
отклоняются. Новые поля необязательны для старых проектов.

`core/equipment.js` задаёт слоты, параметры вещей и отношения групп.
`core/game.js` хранит владение, экипировку, здоровье персонажей и агрессию.
Вещь с `itemOwner` доступна после смерти владельца; инвентарь и позиции
выброшенных вещей исключают повторную выдачу добычи. Сохранения проверяют
слоты и ссылки до замены состояния.

`render/enemies.js` управляет врагами и боевыми действиями NPC: замечает,
преследует, бьёт, убегает, гуляет, показывает смерть и тело. Поиск целей
использует пространственные ячейки и обновляется раз в 0,3 секунды.
`render/npcs.js` отвечает за покой и разговор, уступая боевой анимации.
`render/inventory.js` показывает экипировку, осмотр и обыск;
`hero-doll.js` собирает куклу, не меняя модели мира.

`editor/character-settings.js` содержит формы вещей, поведения и добычи.
Мобильные панели, сохранение редактора одним HTML и сборка GitHub Pages
используют тот же код. Скрипт `single-html.mjs` встраивает код, материалы,
обработчик моделей и лицензии сторонних библиотек.

Ограничения: кукла — встроенный манекен, модели брони размещаются по слотам
без автоматического переноса на скелет героя. AI ходит по рельефу и проверяет
столкновения, но не строит путь вокруг лабиринтов. Нейтральные NPC мирно
сосуществуют, автоматических разговоров между ними нет. Здоровье, агрессия,
добыча, экипировка и тела сохраняются; живые NPC при загрузке возвращаются
к авторской точке и продолжают поведение. Старое стартовое оружие проекта
сохранено для совместимости; для новых вещей используйте предметы-инвентарь.

Следующие улучшения: навигационная сетка для сложных помещений, подгонка
брони к пользовательскому скелету, стопки расходуемых предметов и торговля.


`generation/adventure.js` создаёт детерминированные проекты v17 из настроек и
seed; `generation/stories.js` задаёт сюжеты. `editor/generator-editor.js` строит
предпросмотр и применяет результат через существующий commit/History.
`core/navigation.js` определяет текущую цель и направление для HUD.
Подробности и ограничения: [GENERATION.md](GENERATION.md).


`generation/maze-layout.js` создаёт связное дерево коридоров, выбирает основной
маршрут, секции и боковые поддеревья. `generation/maze.js` превращает граф в
обычные сущности, диалоги, квесты и механизмы проекта v17.
`core/maze-navigation.js` восстанавливает граф по опорным плиткам и ID стен,
учитывает двери и направляет к ключу, повороту или входу. Карта кешируется по
проекту в WeakMap; состояние ключей и дверей берётся из GameState.


`generation/highlands.js` создаёт три низких городских плато и одно верхнее,
разделяющие гряды, спрофилированные дороги, застройку и связанную историю.
`core/highland-navigation.js` восстанавливает дорожный граф по сущностям
`highland-node-*` / `highland-route-*` и выбирает кратчайший маршрут по дорогам.
Дальность камеры и тумана масштабируется с размером мира; обзор редактора
адаптируется к большим картам. Форматы проекта и сохранений прежние.
