Hearth Engine / Залтан 0.35 — проверка поставки

230/230 автоматических тестов пройдено (215 общих + 15 игровых).
Проверены: крепление и движение оружия, удар выбранной рукой, GLB-клипы,
подгонка и отмена предпросмотра, маунт с произвольной посадкой и поворотом,
ходьба/бег, спешивание, сохранение/загрузка и совместимость старого RPG.
Существующие проверки дальнего боя, событий, квестов и географии прошли.

Редактор и игра собраны Vite. Автономные HTML содержат встроенные данные,
ресурсы и синтаксически корректные скрипты без внешних script/link.
Содержимое игры совпадает с zaltan.hearth.json; редактор открывает нейтральный пример.
В исходной карте 0.34 изменены только формат проекта и настройки маунта.
Проверен сейв, записанный настоящим кодом 0.34: пешком и верхом,
инвентарь, золото и прогресс заданий сохраняются.

Формат проекта: 22. Формат сейва: 8. Версия контента Залтана: 4.
230 тестов: node --test --test-concurrency=1 --test-reporter=tap tests/*.test.js
Сборка игры: npm run game -- --project project/zaltan.hearth.json

Chromium в среде проверки не запустился, поэтому визуальная проверка
в браузере не завершена. FPS на пользовательском компьютере не измерялся.
