# Hearth 0.24.0

- Процедурные приключения: seed, три сюжета, три окружения, три размера и три
  уровня сложности. Предпросмотр и создание мира одной транзакцией с отменой.
- Расследование, свидетель, две взаимоисключающие финальные ветки; до трёх
  побочных заданий. Помощь поселению меняет эпилог каждого финала.
- Связанные светлыми каменными тропами локации, плавный рельеф, стартовое
  снаряжение, безопасные NPC, враги и памятные механизмы.
- Указатель направления к цели, расстояние и координаты в игровом HUD.
- CLI `npm run generate`, пример проекта и готовая игра в dist-game/game.html.
- Форматы проекта v17 и сохранения v6 не изменены.
- Восстановлен package-lock.json: исходный lock ссылался на недоступный архив
  decimal.js 10.8.0. Прямые версии three, zod, vite и jsdom сохранены; lock заново
  разрешает их зависимости. Используйте npm ci.

Проверки: 162 теста прошли (включая 8 новых тестов генератора и его формы,
120 seed, 18 комбинаций сюжет/ветка/побочные задания и 12 миров с проверкой
проходимости через moveCharacter и коллизии). Интеграционный тест редактора
также проверяет генерацию, экспорт и отмену. Собраны редактор, автономный
редактор HTML и автономная игра-пример. Визуальная проверка настоящего WebGL
в браузере в среде разработки не выполнена; DOM-тесты используют заглушку GPU.

Ограничения сюжетной генерации и руководство: GENERATION.md.
