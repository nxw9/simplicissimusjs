# Генератор приключений · Hearth 0.24

В редакторе нажмите **✦ Создать приключение**. Выберите сюжет, окружение,
размер мира, сложность боя и число побочных заданий. «Предпросмотр» показывает
завязку, не изменяя текущую сцену. «Создать игру» применяет результат целиком;
старую сцену можно вернуть через ↶. Нажмите **▶ Играть** и поговорите с
хранителем возле точки появления. В меню игры начните новую игру.

Одинаковые seed и настройки в одной версии генератора дают одинаковый проект,
включая ID, рельеф, персонажей и квесты. У разных настроек разные ID: игровые
сейвы не смешиваются. Код мира и все настройки записаны в объекте
«Карта и летопись путешествия» у старта; его можно осмотреть клавишей E.

## Что создаётся

- Три сценария с авторской причинно-следственной основой: «Угасающий огонь»,
  «Город без памяти» и «Бунт древнего леса».
- Поселение, архив, лагерь свидетеля, роща, башня и святилище. Seed меняет
  названия, имена, размещение мест, рельеф и декорации.
- Основная цепочка: найти документ → подтвердить свидетельство → выбрать
  судьбу поселения → выполнить одну из двух финальных задач → получить эпилог.
- Два взаимоисключающих пути: сохранение силы с её ценой или освобождение
  ценой отказа от неё. Выбор фиксируется при принятии финального задания.
- До трёх последовательных побочных заданий: помочь поселению, победить двух
  мародёров, вернуть семейный компас. Первое меняет последствия обоих финалов.
  Помощь, оказанная после финала, тоже учитывается в новом разговоре.
- Стартовые клинок и куртка (экипировка через I), защищённые от убийства
  сюжетные NPC, разные параметры врагов и два памятных знака, которые
  поднимаются после соответствующего финала.
- Указатель ближайшей цели первого активного задания: направление относительно
  взгляда, расстояние и координаты. После выполнения цели он ведёт к NPC для
  сдачи. Если активных заданий нет — к ближайшему NPC с доступным заданием.

За одно прохождение доступны 3 основных задания и 0–3 побочных. В редакторе
видны обе финальные ветки, поэтому общее число квестов на один больше.
Найденные заранее предметы и уже побеждённые враги засчитываются. Для сдачи
предмет должен оставаться в инвентаре: выброшенную вещь можно забрать снова.
Сдача квеста не расходует предмет; это существующее правило Hearth.

## Управление и экспорт

WASD — движение, Shift — бег, E — осмотр и разговор, I — инвентарь,
ЛКМ — удар, Esc — меню. Светлые тропы соединяют поселение с локациями.
В разговорах нужно отдельно принимать и сдавать задания. После сдачи иногда
нужно снова поговорить с NPC, чтобы перейти к следующей теме.

Проект остаётся обычным Hearth JSON v17: можно менять объекты, диалоги,
квесты и модели существующими инструментами. Генератор не требует сервера,
модели AI, ключей или внешнего API. Экспорт «Скачать игру HTML» работает
автономно, в том числе для созданных миров. Форматы проекта и сейва не изменены.

Командная строка (Node.js >= 22.12):

```sh
npm ci
npm run generate -- --seed winter-42 --story ember --size medium --difficulty normal --side-quests 3 --output my-adventure.hearth.json
npm run game -- --project my-adventure.hearth.json
```

Откройте `dist-game/game.html` для автономной игры. Генератор CLI не
перезаписывает существующие файлы: укажите другое имя через `--output`.
Все параметры доступны через `npm run generate -- --help`.

API:

```js
import { generateAdventure } from './src/generation/adventure.js';
const project = generateAdventure({
  seed: 'winter-42', story: 'ember', biome: 'story',
  size: 'medium', difficulty: 'normal', sideQuests: 3,
});
```

`story`: random / ember / mist / roots; `biome`: story / forest / marsh /
autumn; `size`: small / medium / large (100 / 140 / 180 м); `difficulty`:
story / normal / hard; `sideQuests`: целое 0–3. Seed — строка 1–80 символов.
Пробелы по краям seed удаляются. Версия алгоритма — `GENERATOR_VERSION`.

## Устройство и проверки

`generation/stories.js` содержит сценарии и палитры. `generation/adventure.js`
строит полностью валидируемый проект: детерминированный PRNG, условные реплики,
задания, плоские проходы, плавные холмы, зарезервированные площадки и окружение.
При генерации объекты окружения не ставятся на тропы и площадки. Расстановка
имеет ограниченное число попыток и не может зависнуть на неудачном seed.

Сюжетные условия используют существующие Conversation и quest-состояния.
Развилка защищена условиями диалога, сохранения запоминают принятые задания.
Низкоуровневый GameState.questAction сохраняет прежний контракт и сам по себе
не интерпретирует сюжетные условия: для пользовательского UI используйте
Conversation. Ручное изменение автором диалогов может изменить ограничения.

Тесты проверяют 120 seed, обе ветки всех сценариев, ранний сбор предметов,
переходы и награды через Conversation, загрузку сейвов между этапами,
эпилоги до/после помощи, навигацию, предпросмотр и ошибки применения формы.
Проходимость троп проверяется с реальными коллизиями пропов и moveCharacter.

Это генерация небольших приключений из сюжетных шаблонов, а не бесконечная
генерация произвольного текста. Варианты одного сценария сохраняют его основной
конфликт. Новые сюжетные схемы можно добавить в stories.js и adventure.js.
Навигация показывает направление по прямой, не строит маршрут обхода стен;
для исходного мира предусмотрены открытые тропы. Сюжет не включает новые
механики торговли, лечения или автоматическое озвучивание.

## Лабиринты (0.25)

В форме появился параметр «Вид игры». Для лабиринта выберите
«Лабиринт · ключи и двери», либо передайте CLI `--mode maze` / API
`mode: 'maze'`. Это отдельный сценарий со стартом снаружи, последовательными
ключами и квестовыми печатями. [Подробное руководство](MAZE.md).

## Холмистые города (0.26)

«Вид игры → Холмистые города · общий сюжет» / CLI `--mode highlands` / API
`mode: 'highlands'`: три скрытых за грядами нижних города, четвёртый на вершине,
связанный сюжет о караванах и воде, две развязки, побочные истории.
[Руководство](HIGHLANDS.md).
